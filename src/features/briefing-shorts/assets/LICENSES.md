# 브리핑 쇼츠 캐릭터 모델 (#898)

두 파일 모두 제작자(paul)가 **VRoid Studio(아이패드)** 로 직접 만든 러너다(2026-11-05, VRM 1.0).
원본에서 `tools/briefing-shorts/optimize-vrm.mjs` 로 썸네일을 8×8 로 줄이고 표정 모프의 노멀 변화량을 뺐다(10.7MB → 6.4MB, 10.9MB → 6.7MB).

## 이용 조건 — VRoid Studio 가이드라인 (https://vroid.com/en/studio/guidelines, 2023-12-21 판)
- VRoid Studio 기본 파츠(몸·얼굴·머리·속옷·신발 메시·텍스처)는 pixiv Inc. 제공물이고 **CC0 가 아니다**. 특별 조항이 없는 파츠는 개인·법인 누구나 상업적으로 쓸 수 있다 — 앱·게임에 넣어 수익을 내는 것, 다른 프로그램으로 편집하는 것 포함.
- **금지**: VRoid 메시·텍스처를 변형·조합해 3D 모델·아바타를 만들거나 내보내는 앱(캐릭터 제작 도구)을 만드는 것 — 별도 라이선스가 필요하다. 이 앱은 정해진 두 모델에 장면 안에서 옷을 덧입혀 보여 줄 뿐 모델을 만들거나 내보내지 않는다. 사용자가 아바타를 꾸미는 기능을 넣는다면 그 전에 pixiv 라이선스를 먼저 확인할 것.
- pixiv 가 지지·협업한 것처럼 보이게 하지 않는다.

## VRM 메타(제작자 선언 — 파일에 들어 있는 값)
- 두 파일 모두: 아바타 사용 = 제작자만 · 상업 이용 = 법인까지 · 수정 = 허용 · **재배포 = 금지** · 크레딧 = 불필요
- 내보낼 때 들어간 값(여자: 비영리·수정 금지·재배포 허용 / 남자: 개인 영리·크레딧 필요·수정 금지)이 쓰임새(앱 유료화·경량화 수정)와 어긋나 제작자 결정으로 고쳤다(2026-11-05). 원본에서 다시 경량화하면 메타가 되돌아가니 VRoid Studio 내보내기 때 이 값으로 고르거나 다시 고친다.

## 모델을 바꿀 때 지킬 것 (장면 `scene/briefingScene.js` 가 기대하는 모양)
- **속옷만 + 운동화**: 러닝복·모자·소품은 장면이 몸 위에 짓는다(원래 옷에 기대지 않는다). 신발은 짓지 않는다.
- VRoid Studio 내보내기: 투명 메시 지우기 **끔**(옷 밑 피부가 있어야 옷을 짓는다) · 재질 줄이기 안 함(재질 이름으로 부위를 찾는다) · 머리카락 메시 병합 · 머리 뼈대 줄이기 0.
- 여자 머리: 정수리 뒤에 묶은 포니테일(가닥 `J_Sec_Hair*_02`)은 모자를 쓰면 뒤 구멍 높이로 내려 묶고, 바보털(`J_Sec_Hair*_01`)은 지운다. 머리를 바꾸면 `OUTFITS` 의 가닥 이름·모자 치수를 다시 맞춘다.
