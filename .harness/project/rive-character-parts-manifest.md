# Rive 러너 캐릭터 — 파츠 매니페스트 (설계 SSOT)

> 목적: "성별·나이·날씨·계절·러닝유형 등 **인자를 넣으면 캐릭터가 그에 맞게 애니메이션**되는" 앱 기능의 캐릭터 시스템 설계 단일 진실 출처.
> 상태: **설계/PoC 단계.** 현재 구현 검증은 마켓 "Bear running" 리그를 대역으로 진행(최종은 사람 캐릭터). PoC 상세는 메모리 [[rive-runner-character-poc]].

---

## 0. 핵심 원칙
1. **요인을 "모션 축" vs "외형 축"으로 가른다.** 모션은 키프레임 파라미터로 공짜, 외형만 그림 자산 필요.
2. **외형 축은 통짜 캐릭터가 아니라 "독립 레이어 슬롯"으로 조합한다.** 조합 폭발(N×M×K) 방지 → 슬롯 합(N+M+K)으로 커버.
3. **그릴 파츠 목록을 최소화한다.** 색/틴트/실루엣/파티클/포즈는 코드로. 실제 일러스트가 필요한 건 "의상" 정도.

---

## 1. 축 → 메커니즘 매핑

| 축 | 성격 | 구현 메커니즘 | 그림 필요 |
|---|---|---|---|
| **러닝유형**(Easy/Recovery/Tempo/Interval/LSD) | 모션 | 키프레임 계수(stride/arms/bounce/lean) + fps(케이던스) | ❌ |
| **나이대**(청년/장년/노년) | 모션 + 약간 외형 | 모션 계수 배수 + 흰머리(색 바인드) + 구부정(척추 회전) | 거의 ❌ |
| **성별/체형** | 외형(실루엣) | base 실루엣 1~2종 + 프로포션 스케일 | 소(base) |
| **피부/머리/옷 색** | 색 | 데이터바인드 color | ❌ |
| **날씨**(맑음/비/눈/더위/추위) | 외형(의상) + 오버레이 | 겉옷 슬롯 on/off + 비·눈 파티클 + 땀 + 틴트 | ✅ 의상 |
| **계절**(봄/여름/가을/겨울) | 대부분 날씨 재활용 | 의상 무게 + 팔레트 + (선택)배경 | 재활용 |
| **시간대**(주/야) | 색 | 틴트/배경 팔레트 | ❌ |

## 2. 슬롯 아키텍처 (조합 폭발 방지)

```
Base Rig (성별/체형 1~2종, 공통 스켈레톤)
 ├─ 상의 슬롯   Solo{ none / 반팔 / 바람막이 / 우비 }
 ├─ 하의 슬롯   Solo{ 반바지 / 레깅스 }
 ├─ 머리 슬롯   { 헤어 색 바인드 (+선택: 모자) }
 ├─ 액세서리    { 선글라스 / 캡 } (optional on/off)
 ├─ 오버레이    파티클{ 비 / 눈 } + 땀
 └─ 팔레트/틴트  color 바인드 (계절·시간대)
```

- 슬롯은 **동일 스켈레톤(본)에 결합**되어 러닝 모션을 그대로 따라감(skin/attachment 개념).
- Rive 구현: **Solo(배타적 표시)** + **Nested Artboard/Component** + **데이터바인드(visibility/color)**.

---

## 3. 파라미터 엔진 (모션 축, 그림 0)

생성기 구조: 각 트랙 값 = `mean + factor × (baseValue − mean)`, 케이던스 = `fps`. (스크립트: scratchpad/gen_kf.py, gen_combo.py)

**러닝유형 계수(장년 기준, 생체역학):**

| 유형 | stride | arms | bounce | lean | fps(≈spm) |
|---|---|---|---|---|---|
| Easy | 0.85 | 0.70 | 0.60 | -0.05 | 107(160) |
| Recovery | 0.70 | 0.55 | 0.50 | 0 | 104(156) |
| Tempo | 1.05 | 0.95 | 0.60 | -0.12 | 99(175) |
| Interval | 1.30 | 1.20 | 0.70 | -0.18 | 124(186) |
| LSD | 0.80 | 0.70 | 0.55 | 0 | 105(158) |
(수직 바운스는 linear 보간 = 정점 hang 제거)

**나이 배수(유형 계수에 곱):**

| 나이 | strideMul | armsMul | bounceMul | leanAdd | cadMul |
|---|---|---|---|---|---|
| 청년 | 1.10 | 1.10 | 1.15 | +0.02 | 1.05 |
| 장년 | 1.00 | 1.00 | 1.00 | 0 | 1.00 |
| 노년 | 0.70 | 0.65 | 0.60 | -0.15 | 0.85 |

→ **유형 × 나이 = 계수곱으로 자동 생성**(시연 완료: 청년/노년 × Easy/Interval).

**축 조합 전략:** v1 = 필요한 조합만 **bake**(계수곱). 축 늘면 → **additive blend 레이어**(나이=자세보정 레이어를 러닝유형 위에 얹음, 앱은 축 독립 세팅, 매트릭스 미굽음)로 이행.

## 4. 최소 그림(일러스트) 쇼핑 리스트

파라미터로 못 만드는, **실제로 그려야 하는 것만**:
- Base 러너 실루엣 **1~2종**(성별/체형) — 스켈레톤 결합형
- 상의 **3**(반팔/바람막이/우비), 하의 **2**(반바지/레깅스)
- 액세서리 **2**(캡/선글라스)
- 오버레이: 비 파티클, 눈 파티클(각 1)
- 나머지(색·틴트·팔레트·포즈·구부정·흰머리·나이/유형 모션)는 **코드**.

→ 슬롯 독립이므로 이 소수 파츠로 대부분의 룩 커버.

## 5. Rive 구현 계약 (런타임 인터페이스)

앱이 세팅할 ViewModel 프로퍼티(예시):
- `runType`: number/enum 0~4
- `age`: number/enum 0~2
- `gender`: number/enum
- `weather`: enum(clear/rain/snow/hot/cold) → 상의 Solo + 파티클 + 틴트
- `season`: enum → 팔레트 + 의상 무게
- 색: `hairColor`/`skinColor`/`topColor` (color 바인드)

State Machine: 모션 축은 상태 전환(현 곰 PoC의 mesh+condition 패턴), 외형 축은 Solo/visibility/color 데이터바인드. (전환 조건 값 주입은 MCP `set_property_values` 우회 필요 — [[rive-runner-character-poc]])

## 6. 캐릭터(그림) 확보 경로 & 추천

- **A. Rive 아티스트 외주** — 뼈대+모듈 옷장을 이 매니페스트 슬롯 계약대로. 품질 확실, 비용·리드타임.
- **B. 마켓/커뮤니티** — 옷 스왑 모듈 킷 재활용. 싸나 스펙 적합 불확실.
- **C. AI 이미지 생성 → 리깅** — 파츠 이미지 생성 후 Rive 결합. 빠르나 스타일 일관성·리깅 병목.
- **D. 플랫 벡터 = Claude가 MCP로 직접 제작** — **검증됨**: `path_editor.createShapes`로 도형 생성 + 회전 리깅 + 애니 전부 가능(무료). 러닝 앱에 어울리는 미니멀 플랫이면 v1 자급 가능.

**추천: D로 v1 자급(플랫) → 리치 품질 필요 시 C/A로 그림만 교체(뼈대·로직·슬롯은 Claude 몫).** 그림 필요량은 4장 리스트로 최소화.

## 7. 현 시점 검증된 사실 / 제약
- ✅ Claude+MCP로: 아트보드·벡터도형 생성, 본/회전 리깅, 키프레임 애니, State Machine·ViewModel·데이터바인드, 계수곱 조합 자동생성.
- ⚠️ 전환/조건 생성 MCP 함정 → 우회법 확립([[rive-runner-character-poc]]).
- ⚠️ runtime `.riv` export는 Rive 유료(Cadet 월$17). 무료는 에디터 프리뷰 검증만. 출시 시 유료 필요.
- ⚠️ Claude는 래스터 이미지 생성 불가(플랫 벡터는 코드로 가능).

## 8. 로드맵
1. v1 축 확정(예: 러닝유형[완료] + 나이 + 날씨3 + 성별2, 계절은 후순위)
