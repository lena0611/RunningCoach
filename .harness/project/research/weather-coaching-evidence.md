**⚠ 2차 교차검증(Codex, 2026-08-26) 에서 잡힌 우리 쪽 오류 3건 — 전부 반영함**

1. **Stull 인과 설명 오류(우리 SSOT 초안)** — "그늘 기준이라 실제 WBGT 보다 낮다"고 썼으나, Stull 은 **습구온도(Tw) 근사이지 "그늘 WBGT" 가 아니다.** 자연습구온도(Tnwb)·흑구온도·일사·풍속을 포함하지 않는 다른 값이다. 방향이 대체로 낮은 쪽이어도 **차이의 방향·크기를 고정 가정하면 안 된다.** → "WBGT 가 아니며 복사열을 누락해 과소평가할 수 있다"로 교정.
2. **안전 밴드 활성화 조건이 느슨했음** — "일사량 확보 후"로 적었으나 일사량 하나 추가로 WBGT 산출이 검증되지는 않는다. Liljegren 등 검증된 추정기 + 직사광선/그늘 구분 + provenance + 시간 정렬 + 결측 정책까지 조건에 포함. Open-Meteo `shortwave_radiation` 은 **직전 1시간 평균**이고 순간값은 `*_instant` 라는 점도 검증 대상.
3. **증상 기반 중단이 규범이 아니라 문구 예시에 있었음** — WBGT 없이도 **오늘 작동하는 유일한 안전 규칙**인데 커뮤니케이션 절에만 있었다. SSOT 규범 규칙으로 승격.

**⚠ SSOT ↔ 런타임 충돌 발견·수정(2026-08-26)** — 문서만 쓰고 기존 런타임을 감사하지 않아 생긴 모순(`[[audit-existing-domain-before-new-logic]]` 위반). `runningWeather.ts` 가 스스로를 "러닝 강도·안전 판단의 **단일 출처**"로 선언하고 **체감온도 28℃ 를 사실상의 안전 밴드**로, 그 외를 `'러닝하기 무난'` 으로 **안전 보증**하고 있었다 — SSOT 가 금지한 바로 그것. → 안내(advisory)로 성격 재정의, 보증 문구 제거, 계약 가드 테스트 추가.

**⚠ 이 프로젝트에서 확인한 인용 해석 오류 1건**: 본문 §D 의 "대한민국 기상청은 2026년부터 간이 WBGT 정보를 제공" 은 사실이나, 실물을 열어보니 **기후변화 상황지도(climate.go.kr/atlas)** 용 — 행정구역별 2100년까지의 추세·전망을 보여주는 **기후통계 산출물이지 실시간 지점 예보 API 가 아니다.** 밴드도 ISO 7243 작업강도별(33+/30-33/28-30/26-28/<25)이라 JSPO 스포츠 표와 다른 체계다. 기상청 공개 API(생활기상지수 4.0 = 자외선·대기정체 / 꽃가루·감기)에도 WBGT 는 없다. **우리 파이프라인에서 WBGT 를 직접 받을 경로는 현재 없다.**

## 0. 요약 — 확정된 것 / 불확실한 것 / 근거 없는 것

### 확정된 것

- 더위에서는 같은 절대 페이스의 생리적 부담이 커지고, 같은 주관적 노력으로 달리면 속도·파워가 내려간다. 습도는 땀의 증발을 방해하므로 기온만 봐서는 안 된다.
- 더위의 심박 반응은 시간, 강도, 순응 상태, 체격, 수분 상태에 따라 크게 달라진다. 모든 러너에게 적용할 `기온 X℃이면 +N bpm` 표는 현재 근거로 만들 수 없다.
- Easy/Recovery 의 목적은 서늘한 날의 페이스 재현이 아니라 낮은 **상대 강도** 유지다. 대화 가능성·RPE 는 유효한 강도 신호이며, 페이스는 낮춰야 한다.
- 그렇다고 심박 상한을 일률적으로 `+N bpm` 올리는 것도 근거가 없다. 더위로 오른 심박은 측정 잡음이 아니라 실제 심혈관 부담이기도 하다.
- 따라서 핵심 답은 **"심박을 버리고 RPE 만 본다"도 "상한을 무조건 고수한다"도 아니다.** 안전을 먼저 확인하고, Easy 목적은 RPE·대화 가능성으로 판정하되 심박은 경고 신호로 유지한다. 충돌이 크면 걷기·시간 단축·실내/서늘한 시간대로 바꾸며, 사후에는 실패가 아니라 `날씨 교란` 으로 처리한다.
- 열순응은 대체로 첫 주에 상당 부분 생기고, 1~2주 반복 노출에서 더 완성된다. 더운 환경의 심박·체온·불쾌감과 수행은 개선된다.
- WBGT 는 기온보다 나은 환경 위험 지표지만 개인의 심부체온이나 안전을 직접 측정하지 않는다. 증상과 개인 위험요인이 언제나 우선한다.
- 위 원칙은 50대 초보에게만 해당하지 않는다. **안전 우선, 상대강도 유지, 페이스 비교 보류, 개인 기준선 학습**은 일반 성인 러너의 공통 코어로 쓸 수 있다.
- 성별만으로 WBGT·심박·페이스 한계를 다르게 줄 근거는 없다. 월경주기·임신·폐경 등은 성별 계수 하나가 아니라 증상과 생애단계가 확인될 때 별도 경로로 다뤄야 한다.
- 50대라는 이유만으로 자동 고위험 처리할 근거는 없다. 65세 이상은 공중보건상 별도 고위험군으로 보수성을 높이되, 나이보다 질환·약물·열순응·최근 활동이 실제 결정에 더 직접적이다.
- 초보·아마추어·숙련·엘리트는 날씨에 대한 노출시간과 활용 가능한 개인 데이터가 다르다. **숙련도가 안전 면허는 아니며**, 숙련자도 높은 상대강도에서는 큰 열부담을 받을 수 있다.
- 기온·체감온도·습도·바람은 서로 대체할 수 없는 입력이다. 체감온도는 소통용, WBGT 는 환경 위험 게이트, 개별 기상값은 원인 설명과 불확실성 표시에 사용하는 것이 타당하다.

### 불확실한 것

- 열순응이 서늘한 9월·가을 경기력까지 올려 주는지는 상충한다. 작은 연구 하나는 이득을, 다른 교차연구는 이득 없음을 보였다. **"여름 적금이 가을에 이자로 돌아온다"는 약속은 할 수 없다.**
- 고온·고습에서 개인 심박이 몇 bpm 오르고 페이스가 몇 초/km 느려지는지는 개인 데이터로 학습할 수는 있지만, 공개 연구만으로 범용식을 정할 수 없다.
- 저강도 훈련의 최소 유효 강도는 저체력자에서 약 30~45% VO₂ reserve 라는 오래된 종합분석이 있으나, 더위 속 러닝·부상 복귀자를 직접 검증한 값은 아니다.
- 추위에서 웜업을 더 길게 하면 수행 준비에는 도움이 될 수 있으나, 특정 분수의 웜업이 러닝 부상을 예방한다는 직접 근거는 부족하다.
- 코치가 날씨 조정을 설명하면 신뢰·지속률이 좋아지는지에 대한 러너 대상 직접 연구는 거의 없다. 개인화·선택권·근거 설명이 순응도에 유리하다는 일반 운동행동 근거만 있다.
- 남녀, 18~49/50~64/65세 이상, 초보/숙련자별로 몇 bpm 또는 몇 초/km 를 보정해야 하는지는 직접 검증된 범용값이 없다.
- 폐경, 호르몬 치료, 임신·산후의 각 단계에 일반 러닝 앱이 적용할 수 있는 날씨별 수치표는 부족하다. 이 영역은 증상 기반 보수 조정과 의료 지침 연결이 우선이다.

### 근거 없는 것 (규칙으로 만들지 않는다)

- 체감온도 또는 WBGT 구간별 범용 `+bpm`, `초/km`, "정상 심박 드리프트" 표.
- `심박-페이스 디커플링 5%`, `후반 +12 bpm` 같은 값을 더위의 정상/실패 경계로 쓰는 보편 규칙.
- Daniels·Pfitzinger·Lydiard·Seiler 가 검증된 공통 "더위 심박 상향 공식" 을 갖고 있다는 주장.
- 더위·습도가 족저근막염이나 아킬레스건병증을 직접 발생·악화시킨다는 신뢰할 만한 근거.
- 여름 훈련을 견디면 가을 서늘한 날에 반드시 추가 경기력 보상을 받는다는 주장.
- `남성/여성`, `10세 연령 증가`, `초보/숙련` 에 고정 bpm·초/km·WBGT 가중치를 부여한 뒤 모두 더하는 조합표.
- 여성은 본질적으로 더위에 약하다거나, 훈련된 러너는 같은 상대강도에서 더위에 자동으로 안전하다는 단정.

### 핵심 질문 B 에 대한 한 문장 답

**Easy 에서 평소 심박 상한을 맞추려면 거의 걸어야 하는 날은, 상한을 임의로 올려 평소 페이스를 쫓지 않는다. 대화 가능한 Easy 노력으로 속도·시간을 낮추고 걷기를 허용하되, 충돌이 계속 크면 실내나 서늘한 시간대로 옮긴다. 사후 평가는 "실패"가 아니라 "날씨로 비교 불가"로 남긴다.**

## 적용 범위와 보정 계층

핵심 원칙은 **일반 성인 러너에게 범용 적용 가능**하다. 다만 "성인 공통"은 모두에게 같은 숫자를 준다는 뜻이 아니다. 공통 안전·강도 원칙 위에 생애단계, 연령, 러너 수준, 질환·약물, 개인 반응을 순서대로 얹는다. 반대로 성별 × 연령 × 수준 × 기상의 모든 조합을 숫자표로 채우는 것은 현재 근거로 불가능하다. **값이 없을 때의 올바른 출력은 임의 보정이 아니라 `no_numeric_correction` 또는 `insufficient_evidence` 다.**

### 권장 의사결정 순서

| 순서 | 판단층 | 입력 | 출력 원칙 |
|---:|---|---|---|
| 0 | 즉시 안전 | 열질환·한랭질환 증상, 흉통·호흡곤란·의식 변화 | 다른 모든 보정보다 우선해 중단·응급 경로 |
| 1 | 성인 공통 | 세션 목적, RPE, talk test, 심박, 지속시간 | `안전 → 상대강도 → 시간 → 거리 → 페이스` |
| 2 | 환경 부담 | WBGT 또는 기온·습도·복사열·바람, 강수·노면 | 위험 게이트와 비교가능성 판단; 범용 bpm 환산 금지 |
| 3 | 개인 위험 | 65세 이상, 임신·산후, 만성질환, 약물, 과거 열질환, 비순응 | 위험을 보수적으로 올리거나 의료 경로 연결; 성과 보너스 금지 |
| 4 | 러너 수준·세션 | 초보/생활체육/훈련된 경쟁/엘리트, Easy/품질/장시간 | 실행 방법과 데이터 신뢰도를 조절; **안전 임계 완화 금지** |
| 5 | 개인 학습 | 동일인의 유사 날씨·코스·세션 이력 | 충분한 데이터에서 기대 범위만 개인화; **안전 상한 상향 금지** |

여러 보정이 동시에 걸리면 점수를 단순 합산하지 않는다. 안전에서는 가장 보수적인 조건을 우선하고, 사후 평가는 `목적 달성`·`강도 통제`·`안전`·`날씨 비교가능성` 을 분리한다.

### 성인 공통 코어

| 항목 | 기본값 | 근거 한계 |
|---|---|---|
| 더운 날 강도 | 같은 페이스를 고집하지 않고 RPE·대화 가능성 중심으로 상대강도를 낮춘다. 심박은 경고 신호로 남긴다. | 개인별 bpm 상승량은 다름 |
| 평가 | 다른 날씨의 페이스·심박을 그대로 비교하지 않고 `weather_confounded` 를 허용한다. | 비교 가능한 개인 기준선이 없으면 정량 판정 불가 |
| 환경 위험 | 가능하면 WBGT 와 증상·순응·복장·세션 길이를 함께 본다. | WBGT 도 개인 심부체온·안전을 보증하지 않음 |
| 추위·바람 | 보온·젖음·노면·상대풍향을 확인하고 점진적으로 워밍업한다. | 일반 겨울용 bpm/초·km 공식 없음 |
| 개인화 | 같은 사람의 유사 세션을 반복 비교한다. | 최소 세션 수와 허용오차는 제품 검증 필요 |

### 성별·생애단계 보정

| 그룹/입력 | 확인된 근거 | 허용되는 보정 | 금지·보류 |
|---|---|---|---|
| 성별만 확인됨 | 40℃·RH 50% 90분 걷기에서 남녀 각 19명의 심부체온 변화·종료값 유사, 발한·혈류 경로는 다름 (Costa 2025) | 동일한 성인 공통 코어. 개인 반응 이력은 별도 학습 | `여성이라서 WBGT -N`, `남성이라서 +N bpm` |
| 월경주기 | 9편·83명 메타분석에서 황체기 운동 전·후 내부체온은 높았으나 운동 심박·발한·피부온 차이는 유의하지 않음 (Giersch 2020) | 사용자가 원할 때 주기보다 **당일 증상·열감·회복**을 입력받아 세션을 낮추거나 이동 | 주기만으로 심박 상한·WBGT·페이스 자동 변경 |
| 여성의 열순응 | 30편 중 22편 메타분석에서 열순응 후 운동 심부체온·심박 감소, 발한 증가 확인 (Kelly 2023) | 여성도 열순응 가능. 충분한 노출 이력을 개인 상태로 사용 | 여성은 열순응이 안 된다는 가정, 남성 프로토콜 효과크기 무조건 복제 |
| 임신 | 통제 조건에서 심부체온 39℃ 초과 미보고, 다만 표본·조건 제한적 (Ravanelli 2018) | **별도 생애단계 모드**, 산전 진료 지침·증상·환경 회피 우선 | 일반 성인 WBGT 표를 안전 보증처럼 사용, 앱이 의료 허가를 대신함 |
| 산후 | 회복 단계·분만 경과·수유·수면·의료 제한이 다양, 러닝 날씨 수치표 근거 부족 | **별도 복귀 모드**에서 의료 제한·증상·수분·회복 우선 | 임신 연구나 일반 성인 수치를 그대로 복제 |
| 폐경·호르몬 치료 | 러닝 날씨 보정값으로 직접 검증된 자료 부족 | 열감·수면·질환·약물·개인 반응으로 조정 | 성별/연령에서 호르몬 상태를 추정해 자동 계산 |

성별은 생리 경로 차이를 설명할 수 있지만 **단독 위험계수는 아니다.** 36편 역학 메타분석에서 남성의 열질환 발생률이 높았으나(통합 IRR 2.28, 95% CI 1.66~3.16) 저자들은 생리보다 행동·노출 차이 가능성을 제시했고(Gifford 2019), 군인 자료 별도 리뷰에서는 질환 정의에 따라 여성 위험이 더 높은 결과도 있어 방향이 일관되지 않았다(Alelle 2020). 성별 필드는 **필수 숫자 보정값이 아니라, 필요한 생애단계·증상 경로를 여는 선택 입력**으로 쓰는 편이 근거에 맞다.

### 연령대 보정

| 연령 | 제품 기본 처리 | 근거와 한계 |
|---|---|---|
| 18~49세 | 성인 공통 코어 | 이 구간도 체력·질환·약물·열순응 개인차가 큼 |
| 50~64세 | **나이만으로 자동 고위험 처리하지 않는다.** 질환·약물·최근 활동·열순응·증상을 별도 확인 | 50~76세 포함 단기 열순응 문헌 12편은 적응 가능성을 보였으나 50세 이상 참가자 96명·전부 사이클링 (Cole 2023) |
| 65세 이상 | 보수적 위험 오버레이: 더 자주 상태 확인, 급격한 폭염·비순응·장시간/품질 세션에서 이동·단축 우선 | CDC 가 65세 이상을 열 고위험군으로 별도 안내. 다만 건강·고체력 고령 러너도 있어 나이만으로 수행 추정 금지 |
| 18세 미만 | **이 성인 모델의 범위 밖.** 보호자·학교/종목 정책 포함 별도 청소년 모드 | 22편·507명 검토에서 아동은 발한이 낮았으나 체온 변화는 일관되게 크지 않았고 여아 자료 부족 (Falk 2026) |

노화는 평균적으로 발한·피부혈류·갈증 및 열감지에 영향을 줄 수 있지만 유산소 체력은 여러 연령에서 체온조절을 개선한다(Kenney 2020). **`10년마다 -N℃`, `50대 +N bpm` 같은 계단식 보정은 만들지 않는다.**

### 러너 수준별 보정

수준은 나이나 단일 페이스가 아니라 `최근 훈련 연속성`·`검증된 역치/심박 자료`·`유사 세션 기록`·`부상/질병 복귀 여부`·`지원 환경` 으로 판정한다. 문헌의 초보·아마추어·훈련자 정의가 제각각이어서 주간 km 하나로 범용 경계를 정할 수 없다.

| 수준 | 판단 특성 | 날씨 보정 운영 |
|---|---|---|
| 신규·비활동/복귀 초보 | 개인 날씨 기준선과 검증된 역치가 거의 없음 | RPE·talk test·증상 우선, 걷기 혼합 허용, 품질보다 연속성과 보수적 환경 이동. 범용 bpm/페이스 보정 금지 |
| 꾸준한 생활체육 러너 | 유사 Easy 세션·회복 기록 축적 | 같은 코스·시간·세션·날씨끼리 개인 기대 범위 학습. **설명·평가용이지 안전 상한 상향용이 아님** |
| 훈련된 경쟁 러너 | 신뢰할 만한 역치·세션 이력, 계획된 품질 훈련 | 개인 역치·환경별 기록 활용, 품질 세션은 목표 출력이 보존되는 시간·실내로 이동. 계획된 열순응 가능하나 **안전 게이트는 동일** |
| 엘리트·현장 지원 | 종목별 검사·코치·의료/현장 지원 | 종목·대회별 프로토콜과 실제 WBGT·냉각·수분 계획. **엘리트의 극한 자료를 일반 소비자 규칙으로 역수입하지 않음** |
| 부상·질병 복귀 | 모든 수준에 겹치는 별도 오버레이 | 날씨보다 통증·일상 기능·24시간 반응·의료 제한 우선. 원래 수준이 높아도 복귀 중에는 보수적으로 |

**수준이 높을수록 항상 열에 안전한 것은 아니다.** 36℃·RH 25% 같은 상대강도 소규모 연구에서 훈련자(n=10)가 비훈련자(n=10)보다 열생산 28% 높고 심부체온 상승도 컸다(Mora-Rodriguez 2010). 반면 실제 하프마라톤에서는 느린 아마추어가 기온·열지수 영향을 더 받았고 저자들은 긴 노출시간을 설명으로 제시했다(Hodgson 2022). 즉 수준은 `초보=항상 더 위험`·`숙련=항상 더 안전` 의 한 축이 아니라 **열생산·노출시간·자기조절·데이터 신뢰도의 서로 다른 축**이다.

### 기상 입력 그룹별 역할

운동 열부담을 만드는 핵심 환경요소는 기온·습도·공기 흐름·평균 복사열이며 활동 강도와 복장도 함께 봐야 한다(Chalmers 2020). **하나의 기상값을 다른 값으로 대체하거나 각 효과를 선형 합산하면 안 된다.**

| 입력 | 의미 | 허용되는 역할 | 하면 안 되는 것 |
|---|---|---|---|
| 기온 | 대류·전도와 전체 열환경의 기본 맥락 | 온도 구간, 개인 유사 세션 검색, 문구 입력 | 단독으로 심박·페이스 보정 확정 |
| 체감온도 | 사람의 일반적 더위/추위 느낌 요약. 기상청 여름형=기온·습도, 겨울형=기온·풍속 | 사용자 소통, 생활 위험 문맥, 원자료 누락 시 저신뢰 보조 신호 | **WBGT 로 간주**, 복사열 포함 표시, 직접 `+bpm` 변환 |
| 상대습도 | 현재 기온에서 포화 근접도. 따뜻할 때 높으면 증발냉각 방해 | 기온과 함께 고습 교란 표시. 가능하면 이슬점·수증기압/WBGT 로 보완 | 온도 보정에 습도 % 독립 가산; 다른 기온의 같은 RH 를 같은 부담으로 취급 |
| 풍속 | 더위엔 대류·증발, 추위엔 풍속냉각 | 방향·돌풍·차폐를 알면 설명 보강, 추위 안전·복장 판단 | 풍향·주자 속도 없이 초/km 보정 |
| 일사·구름·복사열 | 햇빛·주변 표면에서 받는 열 | 야외 WBGT 또는 일사 자료에 포함, 없으면 `radiant_heat_unknown` | 그늘 체감온도로 직사광선 부담을 대체 |
| 강수·젖음·노면 | 젖은 옷의 열손실, 시야·미끄럼·접지 | 추위 안전, 복장·경로·노면 경고, 비교가능성 표시 | 비가 특정 건병증을 직접 악화한다는 가중치 |
| WBGT | 기온·습도·바람·복사열을 야외 활동 위험에 가깝게 묶은 지수 | **안전 게이트**와 운영 정책 | 개인 심부체온·안전 보증·bpm/페이스 점수로 사용 |
| 관측 신뢰도 | 현장 측정/공식 예보/단순 계산/누락 | 결과에 `measured/forecast/estimated/missing` 저장 | 추정 체감온도와 현장 WBGT 를 같은 품질로 표시 |

열지수/체감온도는 대체로 대중의 그늘·가벼운 활동을 설명하고, WBGT 는 야외 고활동에 맞는다(NWS). OSHA 도 작업 열위험 판단에 환경뿐 아니라 작업강도·복장·순응을 함께 보도록 한다. 상대습도는 온도에 종속되므로 생리 설명·개인 모델에서는 이슬점·수증기압 계열이 더 해석하기 쉽고, RH 만 쓸 때는 **반드시 기온과 결합**한다(Davis 2016).

### 조합 규칙

1. `성인 공통 코어` 를 항상 시작점으로 사용한다.
2. 증상·질환·약물·임신·65세 이상·비순응 같은 **위험 오버레이는 완화가 아니라 유지 또는 보수화만** 한다.
3. 러너 수준은 세션 실행 방법과 개인 데이터 신뢰도를 조정하지만 **공식 안전 게이트를 풀지 않는다.**
4. 기상 입력은 먼저 위험과 비교가능성을 판단하고, 이후 충분한 동일인 기록이 있을 때만 개인 기대 범위를 만든다.
5. 성별·연령·수준·기상을 각각 숫자로 바꿔 더하지 않는다. 조합 근거가 없거나 입력이 부족하면 `insufficient_evidence` 를 반환한다.

## A. 열 스트레스가 러닝 지표에 미치는 정량적 영향

### 핵심 결론

더위는 심박·심부체온을 올리고 같은 RPE 에서 외부 출력과 경기 페이스를 낮추지만, 효과 크기는 조건·개인에 따라 넓게 퍼진다. **단일 실험의 `+20 bpm` 이나 대규모 관찰모델의 `3~6%` 를 개인 보정값으로 전환하면 안 된다.** 습도는 독립적으로 증발 냉각과 지속 능력을 떨어뜨리므로 기온 단독보다 WBGT 또는 온도·습도·복사열·바람을 함께 봐야 한다.

### 정량 근거

| 조건 | 관찰값 | 출처·표본 | 실무 신뢰도 |
|---|---:|---|---|
| 35℃·RH 40%·60% VO₂max 사이클 15→45분 | 일정 출력군 심박 약 149→169 bpm(+13%), 일회박출량 -10%, VO₂max -15% | Wingo & Cureton, 원저, n=7 훈련 남성 | 낮음: 작은 고강도 실험 |
| 같은 실험, 심박 일정 유지 시 | 파워 약 -37%, 산소섭취량 약 -24% 필요 | 같은 원저 | 낮음: 러닝·Easy 아님 |
| 37℃ vs 22℃, RPE 15 고정 30분 | 더위에서 사이클 파워 3.14 vs 3.42 W/kg, 약 -8.2% | Roussey 등, n=11 훈련 남성 | 낮음: RPE 15, Easy 아님 |
| 30℃, RH 24/40/60/80%, 70% VO₂max | 탈진시간 68/60/54/46분; 심박의 RH 차이는 유의하지 않음(p=.097) | Maughan 등, n=8 남성 | 중간: 습도의 독립 효과, bpm 보정 불가 |
| ACSM WBGT 위험군별 5km+ 자기조절 달리기 | high 군 종료 심박 185, moderate 181 bpm; **위험군 경계가 여러 결과에서 일관되게 분리되지는 않음** | Blackman 등 2026, 체계적 문헌고찰·메타분석, 43연구/48군 | 중간: 집단 종료값이지 개인 보정값 아님 |
| Apple Watch 야외달리기 | 기온·습도 모델이 약 37.8℃ 에서 산소 수요 3~6% 증가 추정, 저자는 150 bpm 노력에서 약 4.5~9 bpm 으로 환산; 개인 심박 예측 중앙오차 6.1 bpm | Nazaret 등, 7,465명·270,707회 | 중간: 대규모지만 인과·범용식 아님 |
| 7개 마라톤, WBGT 5.1~10 vs 20.1~25℃ | 상위 남성 기록 손실 1.7% vs 4.5%; **느린 주자일수록 영향이 큼** | Ely 등, 장기 경기자료 | 중간: 마라톤 경기이지 Easy 훈련 아님 |
| 6개 대형 마라톤 2001~2010 | 1,791,972 완주 기록에서 기온이 가장 큰 환경 설명변수; 최적점·영향은 수행수준별로 다름 | El Helou 등 | 중간: 인과·개인 초/km 공식 아님 |

### 심박 드리프트

- 심혈관 드리프트는 보통 일정 출력 지속운동 약 10분 이후부터 심박이 오르고 일회박출량이 내려가는 현상이다. 더위에서 커지며 동일 페이스의 상대 대사강도도 함께 오른다(Wingo 등 리뷰).
- 그러나 **WBGT 별 "정상 +N bpm" 경계는 발견하지 못했다.** 드리프트에는 시작 페이스·지속시간·수분·경사·훈련상태·손목센서 오차가 섞인다.
- 따라서 사후 점수는 절대 `+12 bpm` 같은 값만으로 실패를 내리지 말고, **동일 개인의 유사 시간·코스·강도·날씨 기준선**과 비교해야 한다. 기준선이 없으면 `판정 보류` 가 맞다.

### 실무 보정표·공식

- VDOT 공식 코칭 서비스에 Jack Daniels 의 온도별 훈련·경기 페이스 계산기가 있다. **실무 도구이지만 공개 페이지에서 공식 계수·습도 처리·외부 검증 연구를 확인하지 못했다.**
- 마라톤 관찰자료 회귀식은 경기거리·수준·코스에 민감하다. 40분 Easy 의 초/km 보정식으로 쓰는 것은 외삽이다.
- 앱의 체감온도는 사용자 편의 지표일 수 있으나 **복사열을 포함한 현장 WBGT 와 동의어가 아니다.**

> ⚠ 일반화 한계: 기전 실험은 대부분 젊고 훈련된 남성의 사이클링, 경기자료는 자기조절 마라톤이다. 초보의 40분 Easy 에 적용 가능한 보편 bpm·초/km 범위를 지지하지 않는다.

## B. 더위에서 심박 상한 고수 vs RPE 전환 (핵심)

### 핵심 결론

평소 페이스를 유지하려고 심박 상한을 올리는 것은 부적절하다. 반대로 상한 숫자 하나만 지키다 세션 목적과 안전 맥락을 잃는 것도 문제다. **`안전 → RPE/대화 가능한 상대 강도 → 시간 → 거리 → 페이스`** 순서를 유지하고, 심박은 폐기하지 말고 **경고·개인화 데이터**로 쓴다.

### 상황별 판단

| 상황 | 권장 처리 | 이유 |
|---|---|---|
| 심박이 평소보다 높지만 대화 가능·Easy RPE·증상 없음 | 속도를 낮추고 필요하면 짧은 걷기를 섞는다. **평소 페이스는 평가하지 않는다.** | 같은 절대 페이스의 내적 부담이 커진 상태 |
| 평소 상한을 맞추면 대부분 걷게 됨 | 초보·복귀자의 Easy/Recovery 라면 **걷기도 time-on-feet 로 인정.** 계속 달리기 자극이 꼭 필요하면 상한을 풀지 말고 시간대/장소를 바꾼다. | 저체력자는 낮은 강도에도 적응 가능하나, 러닝 특이 자극은 환경 변경이 더 확실 |
| RPE·대화는 Easy 인데 심박만 초과 | **`실패` 가 아니라 `날씨 교란/상한 재검토 후보`.** 일반 +bpm 은 적용하지 않는다. | 심박은 열 부담을 포함하지만 개인 반응폭은 알려지지 않음 |
| RPE 상승·대화 곤란·어지럼·구역·오한·혼동 | 강도 조정 문제가 아니라 **즉시 중단·냉각·필요 시 응급대응** | 안전 신호가 훈련 목표보다 우선 |
| 품질 세션이 날씨 때문에 목표 출력 불가 | 서늘한 시간·실내로 이동하거나 Easy 로 대체 | 열 속에서 억지 수행하면 목표 자극과 회복을 함께 잃음 |

### "너무 느리면 유산소 자극이 사라지는가"

| 근거 | 값 | 해석 |
|---|---:|---|
| Swain & Franklin, 18개 저·중강도 훈련연구 재분석 | 저체력군 약 30% VO₂R, 중·고체력군 약 45% VO₂R 이 최소 유효 강도 후보 | **저자도 역치 근거가 강하지 않다고 명시.** 더위·러닝 복귀 전용 값 아님 |
| 2022 임상 실무 합의문 | 비활동·저체력자에서 약 30~45% VO₂R | 걷기 수준도 초보에겐 유산소 자극일 수 있음 |
| Talk Test 리뷰 | 편안한 대화는 대체로 환기/젖산 역치 아래 | 실용적 상대강도 신호 |

**"40분 채우면 강도 무관 동일 효과"도, "걷기는 유산소 훈련이 아니다"도 근거에 맞지 않는다.** 강도·지속시간·빈도가 함께 용량을 만든다.

### 권위 있는 훈련 체계에서 확인된 범위

| 체계 | 확인된 원칙 | 확인되지 않은 것 |
|---|---|---|
| Daniels | 이상 날씨에 훈련일을 바꾸는 유연성 권고, VDOT 서비스는 온도별 페이스 조정 제공 | 공개 검증된 더위 `+bpm` 공식 |
| Pfitzinger | 개인의 훈련 한계·회복 반응에 따라 강도·양을 낮추는 원칙 | 고온 시 심박 상한 상향표 |
| Lydiard | feeling-based·response-regulated 훈련, 초보의 편안한 연속 움직임 | 온도/WBGT 별 수치 보정 |
| Seiler/폴라라이즈드 | 저강도는 첫 환기/젖산역치 아래 영역 | 열 환경 심박 상한 상향 규칙 |

### 실무 결론

1. **평소 HR 상한은 자동 상향하지 않는다.** 열로 상승한 심박은 실제 부담을 반영한다.
2. **Easy 합격 여부는 RPE·대화 가능성·회복 반응을 우선한다.** 심박 초과만으로 즉시 실패를 주지 않는다.
3. **갈등이 크면 세션을 바꾼다.** 걷기 혼합·시간 단축·분할·실내·서늘한 시간대.
4. **개인 보정은 사후에 학습한다.** 문헌이 표본 수·허용 오차를 정해 주지 않으므로 제품 검증이 필요하다.

> ⚠ 일반화 한계: 최소 유효 강도 연구는 더위 속 초보 러닝을 직접 시험하지 않았다. 심장질환·혈압약 복용·운동 중 증상이 있으면 일반 훈련원칙보다 의료진 지침이 우선한다.

## C. 열순응 — 여름은 손해인가 적금인가

### 핵심 결론

반복 열 노출은 1~2주 안에 **더운 환경의** 심박·체온·발한·불쾌감과 수행을 개선한다. 다만 주 연구대상은 젊고 훈련된 남성이며 **서늘한 날 경기력 전이는 상충한다.**

### 정량 근거

| 항목 | 결과 | 출처·표본 | 신뢰도 |
|---|---:|---|---|
| 적응 기간 | 대부분 첫 주에 발생, 6~10일에 상당 부분, 최적 준비 약 2주 | 2015 열훈련 합의문, IOC 합의문 | 높음: 합의, 개인차 큼 |
| 권장 노출 빈도 | 유도기 주 4회 이상, 유지기 주 2회 수준 | IOC 합의문 | 중간: 주로 선수 준비 |
| 211개 논문 통합 추정 | 안정심박 -5 bpm, 운동말 심박 -17 bpm, 혈장량 +5.6%, 운동말 심부체온 -0.43℃, 발한량 +163 mL/h | Topham 등 2025 Bayesian 정량 리뷰 | 높음: 문헌 규모 큼, 프로토콜 이질성 큼 |
| 자연 계절순응 | 여름 심박 -3~-8 bpm(2연구), 발한량 +0.03~0.53 L/h(11연구), 땀 Na -22~-59%(6연구) | 계절순응 체계적 문헌고찰, 29연구·561명 | 중간: 대부분 건강한 남성 |
| 소실 | 열 노출 없는 하루마다 적응의 약 2.3~2.6% 소실; **재순응은 소실보다 8~12배 빠름** | Daanen 등, 12연구 메타분석 | 중간: "적응분의 %", bpm/일 아님 |

| 연구 | 결과 | 한계 |
|---|---|---|
| Lorenzo 등 | 40℃ 10일 후 13℃ 에서 VO₂max +5%, TT +6% | n=12 훈련 사이클리스트, 대조군 8명 |
| Keiser 등 | 38℃ 10일 후 더위 수행은 개선, **18℃ VO₂max·TT 변화 없음** | n=7 훈련 남성 교차연구 |

**따라서 "여름에도 안전하게 연속성을 지키면 가을 훈련 기반을 잃지 않는다" 까지는 가능하지만, "가을에 열순응 보너스로 더 빨라진다" 는 금지한다.**

> ⚠ 일반화 한계: 열순응 문헌은 선수·군인·젊은 남성 비중이 크다. 초보·고령·여성·만성질환·약물 복용자에서 동일한 크기와 속도를 가정할 수 없다.

## D. 안전 임계 — 코칭과 분리

### 핵심 결론

WBGT 는 위험 등급화에 쓸 수 있지만 **"이 값 아래면 안전" 이라는 보증이 아니다.** 앱은 안전 게이트를 성과 보정 앞에 두고, 위험구간에서는 페이스/심박 조정이 아니라 **단축·이동·중단**을 제안한다. 증상·비순응·질환·약물·수면·음주·급격한 폭염이 숫자보다 우선한다.

### 일본환경성·JSPO WBGT 운동지침 (✅ 원문 검증 완료)

| WBGT | 공식 지침 | 성인 공통 운영 출발점과 위험 오버레이 |
|---:|---|---|
| <21℃ | 통상 안전하나 적절한 수분 보충 | 개인 증상·순응 상태는 계속 확인 |
| 21~<25℃ | 적극적 수분 보충, 열질환 징후 주의 | 평소 계획을 하되 수분·증상·급격한 더위 확인 |
| 25~<28℃ | 자주 휴식·수분, 격한 운동은 30분마다 휴식 | Easy 만 짧게/느리게, 자주 휴식. 품질·장시간 세션 이동 권고 |
| 28~<31℃ | 격한 운동·**지구성 운동 회피**, 비순응자는 중단 | 야외 지속주·품질 세션은 실내/시간대 이동 기본값. 신규·비순응·65세 이상·개인 위험군은 더 보수적으로 |
| ≥31℃ | **원칙적으로 운동 중지** | 야외 러닝 중지 |

세 번째 열은 의료 임계가 아니라 공식 지침을 러닝 제품 운영으로 번역한 **정책 후보**다. 위험 오버레이는 이 기준을 느슨하게 만들지 않고 유지·보수화한다.

### 즉시 중단·대응 신호

| 신호 | 앱 행동 |
|---|---|
| 심한 무력감, 어지럼/실신, 구역·구토, 두통, 심한 경련 | 즉시 중단, 그늘/냉방 이동, 냉각·수분. 호전되지 않으면 의료 도움 |
| 혼동·이상행동·말 어눌함·의식저하·경련 | **열사병 가능 응급상황** — 즉시 119/응급대응·적극 냉각 |
| 더위 중 두근거림·호흡곤란·가슴 증상 | 즉시 중단, 의료 평가 우선 |

### 개인 위험요인과 약물

- CDC 는 65세 이상을 별도 고위험군으로 둔다. **50대 초반이라는 이유만으로 고령 고위험군 자동 분류 근거는 없으나** 초보·비순응·만성질환·과거 열질환은 보수성을 높인다.
- 이뇨제·항콜린성·일부 정신과 약물·베타차단제·ACE 억제제/ARB 등은 체온조절·발한·갈증·혈압에 영향할 수 있다. **앱은 약을 끊거나 바꾸라고 하면 안 되며**, 처방 의료진·약사와 상의하도록 안내한다.
- WBGT 는 개인 심부체온이 아니다. 2026 메타분석도 기존 위험군 경계가 심박·심부체온·수분손실·기록을 일관되게 분리하지 못했다고 보고했다.

> ⚠ 일반화 한계: JSPO 는 스포츠 현장 기준이다. 제품 기준은 지역·그늘·복장·세션 길이·개인 위험을 함께 받아야 하며 **법적·의료적 안전 보증이 아니다.**

## E. 추위·바람

### 핵심 결론

일상적인 한국 겨울 기온에서 심박을 일률적으로 낮추거나 페이스를 보정할 근거는 없다. 추위는 근육 온도·호흡기·말초혈관·노면·젖은 옷과 결합해 문제를 만들며, 바람 영향은 기상 풍속만이 아니라 **주자 속도와 풍향을 합친 상대풍속**에 달려 있다.

### 정량 근거

| 조건 | 관찰값 | 출처·표본 | 해석 |
|---|---:|---|---|
| 5℃ 15분 웜업 후 30분 대기 | 5분 대기보다 이후 수행 약 -4% | 원저, 러너 5명+로워 5명 | 데운 뒤 오래 식히지 말라는 **수행** 근거; 부상예방 증거 아님 |
| -20℃ 트레드밀 | 최대 workload -2.3%, 젖산역치 workload -3.5%, 최대심박 -3.2% | 원저, n=14 훈련 남성 | 극한 실험, 일반 겨울 bpm 보정값 아님 |
| 맞/뒷바람 0·2·4·6 m/s | 4 m/s 미만은 측정 변동 범위; 21.5 km/h 환산 시 VO₂ +2.2%/-3.1% | Yamashita 등, n=14 | 빠른 달리기 맥락, 느린 Easy 에 그대로 적용 불가 |
| 고전 공기저항 | 5 m/s 마라톤 속도 2%, 6 m/s 중거리 4%, 10 m/s 스프린트 7.8% | Davies, **n=3 남성** | 표본이 너무 작아 제품 공식 부적합 |
| 풍속냉각온도 | -27℃ 미만에서 동상 감시 강화 권고 | ACSM 한랭 운동 지침 | 절대 안전선 아님; 젖음·노출시간·피부노출 포함 필요 |

### 운영 해석

- **저온 심박**: 전신 추위에서 심박 변화는 연구마다 작거나 방향이 다르다. `기온 X℃ → -N bpm` 규칙은 만들지 않는다.
- **바람**: `맞바람 풍속 × 상수 = 초/km` 는 잘못이다. 코스 방향·주자속도·순간 돌풍·차폐 없이는 페이스 손실을 분리할 수 없다.
- **웜업**: 실내 또는 바람을 피한 곳에서 점진적으로 올리고 본운동 직전까지 보온. 부상복귀자는 날씨가 아니라 통증·보행·Easy 반응 게이트가 우선.
- **안전**: 젖은 옷과 비는 영하가 아니어도 열손실이 크다. 감각저하·통제되지 않는 떨림·혼동·말/동작 둔화 시 중단·보온·도움 요청.

## F. 외부 조건 × 부상 상호작용

### 핵심 결론

**더위·습도가 족저근막염이나 아킬레스건병증을 직접 일으키거나 악화한다는 신뢰할 만한 근거는 찾지 못했다.** 날씨는 속도 변화·피로·노면·신발·훈련 장소와 행동을 바꿔 간접 영향을 줄 수 있지만, 이를 질환 가중치로 코드화하면 인과를 과장한다.

| 질문 | 확인 결과 | 근거 |
|---|---|---|
| 러닝 부상 전체의 확립 위험요인인가 | 날씨는 일관된 확립 요인으로 제시되지 않음 | 2024 umbrella review, 13개 SR·148 원저; 포함 문헌 질 낮음~매우 낮음 |
| 전향 연구의 주요 위험요인인가 | **과거 부상 이력이 가장 일관**, 전체 근거는 제한적 | 2020 SR, 29연구 |
| 날씨와 근골격 통증 일반 | 대부분의 흔한 근골격 통증과 기온·습도·기압·강수의 연관 없음 | 2024 메타분석, 11연구·15,315명 |

### 실무 결론

- **코드에서 `고온/고습 → 족저근막염 위험 +X` 를 넣지 않는다.**
- 날씨 때문에 실내 트레드밀·다른 신발·경사·노면·주법·시간/거리가 바뀌었다면 **바뀐 훈련부하**를 별도 원인 후보로 본다.
- 부상 판단은 날씨보다 통증 반복·일상 보행 반응·Easy 후 24시간 반응·최근 훈련량 변화가 우선이다.

> ⚠ "연관 근거 없음" 은 절대 영향이 없다는 증명이 아니다. **현재는 특정 질환용 결정론 규칙을 만들 만큼 근거가 없다는 뜻이다.**

## G. 커뮤니케이션과 지속률

### 핵심 결론

날씨 보정 설명 문구와 이탈률의 직접 검증 연구는 부족하다. 다만 운동행동 연구는 **개인화·선택권·명확한 이유·자기효능감·모니터링 피드백**이 지속에 유리함을 반복해서 보인다. 메시지는 "오늘의 숫자가 나빠졌다" 가 아니라 **"목표는 그대로이고 표현 방식만 바뀌었다"** 를 전달해야 한다.

### 권장 메시지 구조 (제품 언어 번역 후보 — RCT 검증 템플릿 아님)

1. **바뀐 것**: "오늘은 열부담이 커서 페이스 비교를 끕니다."
2. **안 바뀐 것**: "Easy 의 목표는 대화 가능한 낮은 노력과 40분의 안전한 움직임입니다."
3. **선택권**: "속도를 낮추거나 걷기를 섞고, 계속 불편하면 실내/서늘한 시간대로 옮기세요."
4. **평가 약속**: "오늘의 느린 페이스와 열로 인한 심박 상승만으로 체력 저하를 판정하지 않습니다."
5. **안전 경계**: "어지럼·혼동·구역·호흡곤란이 있으면 즉시 중단하세요."

## 실무 적용 제안

### 1. 처방 조정 규칙 후보

**보정 컨텍스트** — 필드가 없다고 성별·나이·수준을 추정하지 않는다.

- `populationScope`: `adult_common / youth_separate_policy / pregnancy_or_postpartum_special`
- `riskModifiers`: 65세 이상, 만성질환, 관련 약물, 과거 열질환, 비순응, 급격한 기온 변화, 수면·음주·탈수 우려
- `runnerEvidenceLevel`: `new_or_returning / consistent_recreational / trained_competitive / elite_supported`
- `sessionPurpose`: `recovery / easy / long / quality / race`
- `weatherInputs`: 기온·체감온도·습도·바람·강수·일사/구름·WBGT 와 각각의 출처·시각·신뢰도
- `personalEvidence`: 유사 세션 수, 센서 품질, RPE/talk test 유무, 코스·고도 유사성

**이 필드들은 가산점 계산표가 아니다. 안전 게이트·실행 방식·개인화 가능 여부를 고르는 분기값이다.**

**안전 게이트**

1. WBGT 출처를 `현장 측정 / 공식 예보·추정 / 없음` 으로 구분한다. **체감온도를 WBGT 로 치환하지 않는다.**
2. 증상·개인 고위험 신호가 있으면 날씨 수치와 무관하게 중단 경로로 보낸다.
3. 기본값 후보: <25 일반 주의 / 25~28 Easy 짧게·느리게·자주 휴식, 품질·장시간 이동 권고 / 28~31 야외 지속주·품질 세션 실내·시간대 이동(신규·복귀·비순응·65세+ 는 중단 또는 이동 기본값) / ≥31 야외 러닝 중지.
4. **"공식 절대 안전선" 이 아니라 JSPO 지침을 러닝 운영으로 번역한 제품 정책으로 라벨링한다.**

**Easy/Recovery 강도 게이트**

1. 안전 통과 후 `강도(HR/RPE/대화) → 시간 → 거리 → 페이스` 우선순위 유지.
2. 고온 교란에서는 **페이스 목표와 페이스 기반 실패 판정을 끈다.**
3. RPE·대화가 Easy 이고 증상 없으면 심박 상한 초과만으로 실패시키지 않고 `weather_confounded` 를 붙인다.
4. **심박·RPE·대화가 함께 높으면 강도 실패 또는 중단 판단 유지. 날씨는 면죄부가 아니다.**
5. 상한을 맞추려면 걷기가 필요하면 걷기를 허용. 계속 달리기가 필수 목표면 **숫자 상향이 아니라 실내/시간대 변경**을 권한다.
6. 템포·인터벌·레이스페이스는 더위에서 Easy 로 자동 둔갑시키기보다 **이동·연기·대체 세션으로 명시**한다.

**개인화 후보**

- 동일 사용자의 유사 코스·시간·세션에서 기온·체감온도·습도/WBGT·풍속·일사/구름·강수·RPE·talk test·평균/구간 심박·속도를 함께 저장한다.
- 개인 반응 모델은 **평가 설명과 기대 범위에 먼저** 쓰고, **안전 상한을 올리는 데 쓰지 않는다.**
- 표본 부족·센서 품질 저하·RPE/talk 누락·코스 고도 차이가 크면 보정하지 않고 `insufficient_evidence` 를 반환한다.
- 성별·연령·수준의 집단 평균을 개인 데이터가 없는 자리에 수치로 대입하지 않는다.

### 2. 사후 평가 보정 규칙 후보

- 점수를 `목적 달성 / 강도 통제 / 안전 / 날씨 비교가능성` 으로 **분리**한다. 날씨 교란은 목적 달성 점수를 자동 감점하지 않는다.
- 고온·고습인데 RPE·대화 데이터가 없으면 **심박 드리프트와 페이스만으로 체력 저하를 판정하지 않는다.**
- "평소보다 느림"·"심박이 높음"·"드리프트가 큼" 을 각각 **관찰사실로 보여 주되**, 날씨 조건이 다르면 인과 해석은 보류한다.
- 비교는 가능한 경우 같은 사용자의 유사 세션·유사 조건으로 제한한다. **범용 bpm/초·km 를 빼지 않는다.**
- 열순응 개선은 같은 날씨·유사 RPE 에서 심박/페이스/불쾌감이 **반복적으로** 좋아질 때만 추세로 말한다.
- 기존 `후반 +12 bpm` 경계가 있다면 **더운 날에는 단독 실패 근거로 쓰지 말고** RPE·대화·페이스 붕괴·증상과 결합한다. 문헌은 `+12` 를 보편 정상/비정상선으로 지지하지 않는다.

### 3. 규칙으로 만들면 안 되는 것

- `기온/체감온도/WBGT X → 심박 +N bpm` 범용 보정.
- `X℃ → 페이스 +N초/km` 를 Easy·Recovery·마라톤에 공통 적용.
- 손목 심박의 단일 초과값으로 더위 적응 또는 실패 확정.
- `드리프트 5%` 또는 `+12 bpm` 을 날씨와 무관한 보편 품질선으로 사용.
- VDOT 온도 계산기나 단일 마라톤 회귀식을 검증된 내부 공식처럼 복제.
- 열순응 7/10/14일을 모든 초보에게 강제하거나, 열순응을 위해 위험 날씨에 야외 훈련 유지.
- **"여름을 견디면 9월에 반드시 빨라진다" 는 성과 약속.**
- 습도·기온만으로 족저근막염/아킬레스 위험점수 가산.
- 바람의 절대 풍속만으로 초/km 감점.
- WBGT 기준 아래를 안전 보증으로 표시하거나, 위험 약물의 중단·변경을 앱이 지시.
- RPE·대화·증상 데이터가 없는데 날씨 하나로 심박 초과를 전부 정상 처리.
- 성별만으로 열위험·심박 상한·페이스 보정값을 다르게 설정.
- 월경주기·폐경·호르몬 상태를 성별이나 나이에서 추정하거나 주기만으로 자동 감점.
- 50세를 고위험 절단점으로 사용하거나 10세 증가마다 고정 bpm·WBGT 보정 가산.
- 훈련 수준이 높다는 이유로 WBGT 안전정책 완화, 초보라는 이유만으로 모든 수행 저하를 날씨 탓 처리.
- **체감온도를 WBGT 처럼 사용**하거나, 상대습도를 기온과 독립된 선형 페이스 감점으로 가산.
- 성별 × 연령 × 수준 × 날씨 표의 빈 칸을 인접 그룹 평균이나 코치 직관으로 채움.
